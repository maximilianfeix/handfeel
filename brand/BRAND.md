# handfeel brand

Everything here is generated by `make_brand.py`. To change an asset, change the script and run `python3 brand/make_brand.py`. Never edit a PNG by hand.

## Idea

**A touch that answers.** A fingertip on glass, and the response around it. handfeel exists because generated apps ignore the moment of touch: targets too small to hit, taps that show nothing, no haptics. The mark is that moment done right.

### Concepts considered

| | Concept | Verdict |
|---|---|---|
| 1 | Thumb reach: an arc around the bottom-right corner of a phone, with a dot inside the comfortable zone | Rejected. Mirrored, it reads as the RSS or Wi-Fi symbol. |
| 2 | **Press: a dot (the fingertip) inside an open ring (the response). The ring opens to the bottom right, where a right thumb comes from.** | **Chosen.** It shows the product's promise, works as a single colour, and holds up at 16 px. |
| 3 | A lowercase h whose stem ends in a fingertip | Rejected. Letter marks do not explain the product and fall apart at favicon size. |

## Logo

| File | Use |
|---|---|
| `logo/lockup-light.svg`, `logo/lockup-dark.svg` | Mark + wordmark on light / dark grounds |
| `logo/mark-light.svg`, `logo/mark-dark.svg` | Mark alone (avatars, favicons) |
| `logo/mark-ink.svg` | One colour |
| `favicon/` | 32 px favicon, 180 px touch icon, 512 px icon |
| `banners/` | GitHub social preview (1280×640), X header (1500×500), X avatar, README banners |

- **Wordmark** is always lowercase: `handfeel`. In running text: handfeel.
- **Clear space:** the ring's stroke width × 3 on every side (about 0.3 × mark height).
- **Minimum size:** mark 16 px, lockup 20 px mark height.
- **Don't:** close the ring, rotate it (the gap always points bottom right), put the dot outside the ring, colour the ring clay, add gradients, glows, shadows or glass, place it on purple.

## Colour

| Token | Hex | Role | Contrast |
|---|---|---|---|
| `ink` | `#151412` | Dark ground, text on light | |
| `paper` | `#F4F1EA` | Light ground, text on dark | 16.3:1 on ink |
| `clay` | `#E0592A` | The touch point. Large shapes, and text on ink only | 4.9:1 on ink; 3.3:1 on paper, so no small text on light |
| `clay_text` | `#A6401B` | Clay for links and emphasis on light | 5.5:1 on paper |
| `muted_light` | `#68625A` | Secondary text on paper | 5.3:1 |
| `muted_dark` | `#A49E93` | Secondary text on ink | 6.9:1 |

Contrast values are printed by `make_brand.py` on every run.

There is no purple in this palette on purpose. handfeel flags the indigo-violet accent as the most common tell of a generated app, so the brand does not use it.

## Type

One family: **Bricolage Grotesque** (SIL Open Font License, `fonts/Bricolage-OFL.txt`).

| Role | Settings |
|---|---|
| Wordmark, headlines | 700, opsz 96, tracking −2.5 % |
| Titles | 600, opsz 48 |
| Text | 450, opsz 14 |

Code and terminal output use the reader's monospace font; the brand does not ship one.

## Voice

Plain and specific. Say what the scanner found and where. No exclamation marks, no superlatives, no emoji. Numbers only when they were measured, with the measurement linked.
